# Awesome-MMORPG-Legacy



**Curated List of Commercial Games & Open-Source GitHub Projects**

*Focused on MMORPG Server Emulation, Classic Game Preservation, Open-Source Engines & Community Revivals*

**Last updated: October 2026**



This repository tracks notable **legacy MMORPG platforms** and **open-source projects** that preserve, revive, and reimplement classic massively multiplayer online games. These tools help developers and communities run private servers, reverse-engineer dead games, and build new MMOs on open foundations.



**Examples** include EverQuest, Ultima Online, Dark Age of Camelot, Lineage, Anarchy Online, Star Wars Galaxies, City of Heroes, Final Fantasy XI, Shadowbane, and Asheron's Call (the legacy category leaders).



**Open-source emphasis**: The open-source MMORPG ecosystem is **exceptionally vibrant and preservation-focused**. **OpenMW** reimplements Morrowind's engine with a **1.0 release within reach** and browser-based WebAssembly port in development . **Stendhal** is a free, friendly multiplayer online adventure with an old-school feel and active development . **AzerothCore** and **TrinityCore** power the largest World of Warcraft private server communities . **Illarion** is a non-profit, open-source sandbox MMORPG with isometric graphics and deep player interaction . **Terasology** provides a modular voxel-world engine for building custom MMO experiences .

## 💼 Legacy MMORPG Platforms



> **📊 Market Context**: The legacy MMORPG market is **not a commercial market** — these games are largely **abandoned, unsupported, or running on life support**. The value lies in **preservation, private server communities, and open-source reimplementation**. The **private server ecosystem** is massive: **AzerothCore** and **TrinityCore** alone power thousands of World of Warcraft servers . **City of Heroes** was revived by the **Homecoming** community after the source code leaked in 2019 . **Star Wars Galaxies** lives on through **SWGEmu** . **Asheron's Call** was preserved by **ACEmulator** after Turbine shut down the servers in 2017 . The pattern is clear: **when commercial MMOs die, open-source communities bring them back**.



| Platform | Description | Release Era | Current Status | Preservation Path |

|----------|-------------|-------------|----------------|-------------------|

| **[Asheron's Call](https://en.wikipedia.org/wiki/Asheron%27s_Call)** | **Turbine's groundbreaking 3D MMORPG.** Skill-based progression, allegiance system, and monthly content updates. | **1999–2017** | **Discontinued** — servers shut down January 2017. | **ACEmulator** (open-source server emulator) . |

| **[EverQuest](https://www.everquest.com/)** | **The genre-defining MMORPG.** Group-focused gameplay, raid content, and 20+ expansions. | **1999–present** | **Still running** — Daybreak Game Company operates live servers. | **EQEmulator** (private server emulator), **Project 1999** (classic recreation). |

| **[Ultima Online](https://www.uo.com/)** | **The original sandbox MMORPG.** Player housing, crafting, PvP, and emergent gameplay. | **1997–present** | **Still running** — Broadsword Online Games operates live servers. | **ServUO** (open-source server emulator), **SphereServer**, **RunUO**. |

| **[Dark Age of Camelot](https://www.darkageofcamelot.com/)** | **Realm vs. Realm PvP MMORPG.** Three-faction warfare, siege combat, and class depth. | **2001–present** | **Still running** — Broadsword operates live servers. | **DAoC Emulator** (community server projects). |

| **[Lineage](https://en.wikipedia.org/wiki/Lineage_(video_game))** | **NCSoft's founding MMORPG.** Open PvP, clan warfare, and siege mechanics. Massive in Korea. | **1998–present** | **Still running** in Korea and some regions. | **L1J** (Java server emulator), **L2J** (Lineage 2 emulator). |

| **[Anarchy Online](https://www.anarchy-online.com/)** | **Sci-fi MMORPG with complex skill system.** Free-to-play since 2018. | **2001–present** | **Still running** — Funcom operates live servers. | **AO Emulator** (community projects). |

| **[Star Wars Galaxies](https://en.wikipedia.org/wiki/Star_Wars_Galaxies)** | **Sandbox Star Wars MMORPG.** Player cities, crafting, and profession system. | **2003–2011** | **Discontinued** — SOE shut down December 2011. | **SWGEmu** (open-source server emulator), **Legends** (community server). |

| **[City of Heroes](https://en.wikipedia.org/wiki/City_of_Heroes)** | **Superhero MMORPG.** Costume creator, sidekicking, and task forces. | **2004–2012** | **Discontinued** — NCSoft shut down November 2012. **Revived by community** . | **Homecoming** (community server), **Paragon Chat**, **Thunderspy**. |

| **[Final Fantasy XI](https://www.playonline.com/ff11us/)** | **Square Enix's first MMORPG.** Job system, skillchains, and story-driven content. | **2002–present** | **Still running** — Square Enix operates live servers. | **DarkStar** (open-source server emulator), **LandSandBoat**. |

| **[Shadowbane](https://en.wikipedia.org/wiki/Shadowbane)** | **PvP-focused MMORPG.** Player-built cities, siege warfare, and guild politics. | **2003–2009** | **Discontinued** — Ubisoft shut down 2009. | **Shadowbane Emulator** (community project). |
